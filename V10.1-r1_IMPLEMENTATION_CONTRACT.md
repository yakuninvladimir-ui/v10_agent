# ARC-AGI-3 LCLD Agent — V10.1-r1 Implementation Contract

**Target audience:** Coding agent  
**Base version:** V10.0 (Tri-Agent, Brusentsov judge, SymbolicTrajectoryExecutor)  
**Goal:** Add a clean four-valued verdict system (FOLLOW / NULL / OMIT / UNDECIDED) and a persistent object tracker with change-centric propositions. Strengthen the external judge without rewriting the agent core.

**Hard constraints (do not violate):**
- No learned components inside tracker or verifier.
- No per-step Solver calls.
- All existing ISO-1 … ISO-8 isolation invariants remain in force.
- 5-attempt ceiling and RESET-on-NULL semantics are unchanged.
- Changes are additive. Existing unit tests must continue to pass.
- Keep per-frame latency under 5 ms on 64×64 grids.

### Exact types to introduce

```python
from enum import Enum
from dataclasses import dataclass, field
from typing import Any
import time

class Ternary(Enum):
    """Pure Brusentsov logical values only. Do not put epistemic signals here."""
    TRUE       =  1   # FOLLOW
    FALSE      = -1   # NULL
    IRRELEVANT =  0   # OMIT

class EpistemicSignal(Enum):
    """Controller signals. Not truth values."""
    SEEK_EVIDENCE = 1

class Verdict(Enum):
    """Full judge verdict = logical value or epistemic signal."""
    FOLLOW    = "FOLLOW"      # maps to Ternary.TRUE
    NULL      = "NULL"        # maps to Ternary.FALSE
    OMIT      = "OMIT"        # maps to Ternary.IRRELEVANT
    UNDECIDED = "UNDECIDED"   # maps to EpistemicSignal.SEEK_EVIDENCE

    @property
    def ternary(self) -> Ternary | None:
        if self is Verdict.FOLLOW:
            return Ternary.TRUE
        if self is Verdict.NULL:
            return Ternary.FALSE
        if self is Verdict.OMIT:
            return Ternary.IRRELEVANT
        return None

    @classmethod
    def from_ternary(cls, t: Ternary) -> "Verdict":
        if t is Ternary.TRUE:
            return cls.FOLLOW
        if t is Ternary.FALSE:
            return cls.NULL
        if t is Ternary.IRRELEVANT:
            return cls.OMIT
        raise ValueError(f"Cannot map {t} to Verdict")
```

## Stage 1 — Verdict Decision Order in LayeredVerifier

### Goal
Implement the new strict decision order while still using the legacy ARGA-only observation path.

### Decision order (must be exactly this sequence)

```
1. Terminal WIN / levels_completed increase          → Verdict.FOLLOW
2. Terminal GAME_OVER / LOST / FAILED                → Verdict.NULL
3. Explicit EXPECT contradiction
   (implies_brusentsov returns Ternary.FALSE)       → Verdict.NULL
4. Explicit EXPECT necessary containment             → Verdict.FOLLOW
5. Zero grid delta on a *confirmed* motion action
   (see definition of “compatible effect signature”) → Verdict.NULL
6. Any UNDECIDED condition (see below)               → Verdict.UNDECIDED
7. Positive certificate from GameMemory
   (action_id present AND observed effect matches
    the stored confirmed effect)                     → Verdict.FOLLOW
8. Default (nothing above matched)                   → Verdict.OMIT
```

### Definition: “compatible effect signature”

A confirmed effect stored in `GameMemory.confirmed_action_effects[action_id]` is considered a **motion** effect (and therefore triggers the zero-delta NULL rule) if and only if the effect string contains at least one of:

- `"dy="`, `"dx="`, `"moved"`, `"displace"`

and does **not** contain any of:

- `"blocked"`, `"wall"`, `"no_effect"`, `"null"`.

### UNDECIDED emission conditions (Stage 1, still on legacy ARGA)

Emit `Verdict.UNDECIDED` when any of the following holds (after terminal short-circuits):

1. Ambiguous object matching: more than one after-object inside distance/area tolerance **and** the difference between the best and second-best matching scores is < `matching_ambiguity_threshold`.
2. Zero grid delta on a **non-confirmed** action that carries a non-empty EXPECT set.
3. Detected changes exist but all metric magnitudes < `min_reliable_delta` and no terminal signal is present.
4. Upstream `GroundedStep` or binder sets `confidence="low"` or `matching_status="ambiguous"`.

**ISO-10 (hard rule):**  
A `NULL` verdict may **never** be issued solely because an LLM-generated EXPECT did not match. `NULL` requires a physical contradiction in the observed propositions (destroyed vs preserved, opposite metric sign, area violation, terminal failure, or zero-delta on a confirmed motion action).

### Acceptance for Stage 1
- Unit tests for the new decision order.
- Existing tests still pass (legacy path remains default until Stage 4).
- No automatic conversion of UNDECIDED into OMIT.

## Stage 2 — Executor & Session Reaction to UNDECIDED

### SymbolicTrajectoryExecutor

When `judgment.verdict == Verdict.UNDECIDED`:

```python
return TransitionEvaluationResult(
    verdict=Verdict.UNDECIDED,
    judgment=judgment,
    candidate_advanced=False,
    candidate_severed=False,
    replan_needed=False,
    reset_needed=False,
    evidence_needed=True,
    evidence_hint=judgment.evidence_hint,
)
```

Do **not** call `advance()` or `sever()` on the candidate.  
Do **not** trigger RESET.

### GameSession evidence-seeking loop

Add these fields:

```python
evidence_seeking_active: bool = False
evidence_probes_remaining: int = 0          # reset to config.max_evidence_probes_per_level on new level
undecided_streak: int = 0
pending_step_snapshot: Any | None = None    # immutable snapshot of the step under evaluation
```

#### Behaviour

1. On first UNDECIDED for a given pending step:
   - Set `evidence_seeking_active = True`.
   - Store an immutable snapshot of the pending step.
   - If `evidence_probes_remaining > 0`, enqueue one targeted Explorer probe (hint from `evidence_hint` or a generic discrete/coordinate probe) and decrement the counter.

2. **Blocking mechanism for `act()`** (mandatory, choose this exact behaviour):

   ```
   While evidence_seeking_active is True:
     - act() returns the next probe action from probe_queue (if any).
     - If probe_queue is empty, act() returns
       {"id": "NOOP", "action_id": "NOOP", "data": {}, "reasoning": {"source": "evidence_seeking"}}.
     - act() MUST NOT generate a new trajectory step until the current undecided step is resolved.
   ```

3. After a probe action is executed and the new observation arrives:
   - The environment state has changed.
   - Re-evaluation does **not** re-apply the original pending_step as a transition from the old state.
   - Instead, the system checks whether the **condition that caused UNDECIDED** still holds in the new state.
   - If the ambiguity / low-confidence / zero-delta condition has disappeared → clear `evidence_seeking_active`, resume the trajectory from the next step of the original candidate (or re-issue the same logical step if the candidate cursor was not advanced).
   - If the condition persists → increment `undecided_streak` and either issue another probe or fall through to the streak limit.

4. Streak limit: `max_undecided_streak = 2` consecutive UNDECIDED on the same logical pending step.
   - While probes remain → keep probing.
   - When probes are exhausted → treat as `Verdict.NULL` (sever candidate + clean RESET). This is intentional.

5. Evidence probes do **not** count against `max_chain_attempts_per_level`. They have their own budget.

6. Implement as a flag inside the existing EXECUTING phase. Do **not** add a new `SessionPhase`.

### Interaction with `replan_requested`

When UNDECIDED finally falls through to NULL (probe budget exhausted):
- Sever the candidate exactly as a normal NULL would.
- Do **not** set `replan_requested = True` (this is lack of evidence, not a planning error).
- If the whole candidate pool is exhausted, fall through to the existing pool-exhaustion / replan logic already present in the session.

### Memory rule (ISO-9)

- `UNDECIDED` judgments are written **only** to `EpistemicMemory.epistemic_signals`.
- They never appear in `committed_judgments` as FOLLOW/NULL/OMIT.
- They never mutate the candidate cursor and never trigger RESET.

### Acceptance for Stage 2
- Tests: UNDECIDED does not advance/sever.
- Tests: streak limit → NULL after budget exhaustion.
- Tests: evidence probes do not increment the chain-attempt counter.
- Tests: `act()` returns NOOP / probe while `evidence_seeking_active`.
- No change to the 5-attempt ceiling.

## Stage 3 — PersistentObjectTracker

### Interface

```python
@dataclass
class TrackedObject:
    persistent_id: str
    last_frame_id: int
    color: int
    shape_signature: str
    filled_shape_signature: str
    centroid: Centroid
    bbox: BoundingBox
    area: int
    velocity: tuple[float, float]          # EMA, α = 0.3
    confidence: float                      # defined below
    history: list[tuple[int, Centroid]]    # max length = cumulative_window + 1
    # additional fields
    shape_signature_stable: str
    shape_stability_score: float = 1.0
    occluded: bool = False
    occluded_frames: int = 0
    occluded_by: str | None = None         # persistent_id of occluder or None
    cumulative_delta: tuple[float, float] = (0.0, 0.0)

class PersistentObjectTracker:
    def update(self, snapshot: ARGALiteSnapshot, frame_index: int) -> list[TrackedObject]: ...
    def get_tracked(self) -> list[TrackedObject]: ...
    def reset(self) -> None: ...           # called on every environmental RESET
```

### Matching cost (fixed, normalised to [0, 1])

```
color_diff    = 0.0 if same colour else 1.0
centroid_dist = manhattan(before, after) / max(grid_h, grid_w)
shape_jaccard = jaccard(before_sig, after_sig)
area_rel_diff = abs(before_area - after_area) / max(before_area, after_area, 1)

cost = 0.30 * color_diff
     + 0.40 * centroid_dist
     + 0.20 * (1.0 - shape_jaccard)
     + 0.10 * area_rel_diff
```

Accept match if `cost < config.track_match_threshold` (default 0.45).

### Greedy nearest-neighbour algorithm (exact procedure)

1. Build the full cost matrix (N tracks × M components).
2. Collect all pairs `(track_idx, component_idx, cost)` and sort them by ascending cost.
3. Iterate the sorted list:
   - If the track is still free **and** the component is still free → assign the match.
   - Otherwise skip.
4. On exact cost ties, the pair with the smaller `persistent_id` (lexicographic) wins. This guarantees full determinism.

### Confidence formula (mandatory)

```
confidence = 1.0 - cost
```

where `cost` is the cost of the match that was just accepted for this track.  
For a newly spawned track (no previous match) set `confidence = 1.0`.  
For an occluded track keep the last known confidence (do not recompute).

### Velocity EMA

```
instantaneous = (new_centroid.row - old_centroid.row,
                 new_centroid.col - old_centroid.col)
velocity = 0.3 * instantaneous + 0.7 * previous_velocity
```

α is fixed at 0.3 (not configurable).

### History ring buffer

Maximum length = `config.cumulative_window + 1` (default 4).  
When the buffer exceeds the limit, drop the oldest entry (FIFO).

### Track lifecycle
- Unmatched component → spawn new `trk_XXXX`.
- Track with no match for `track_max_age` frames (default 5) → kill.
- On environmental RESET → full `tracker.reset()`.

### Occlusion heuristic (exact)

If a track has no match **and** there exists at least one component whose area is strictly larger than the track’s last known area **and** whose centroid lies inside `occlusion_radius` (default 3 px) of the track’s last known centroid:

- Set `occluded = True`.
- Set `occluded_by` to the `persistent_id` of the nearest such component (or `"unknown"` if the component is not yet tracked).
- Increment `occluded_frames`.

If the track was previously occluded and a matching component appears again → clear `occluded`, reset `occluded_frames` and `occluded_by`.

### Shape stability (exact rule)

On every update:

```
jaccard = jaccard_similarity(current_signature, shape_signature_stable)
if jaccard < 0.85:
    shape_stability_score *= 0.9
# otherwise leave the score unchanged
```

### Cumulative motion

```
if len(history) >= config.cumulative_window:
    oldest = history[-config.cumulative_window][1]
    newest = centroid
    cumulative_delta = (newest.row - oldest.row, newest.col - oldest.col)
```

### Acceptance for Stage 3
- Unit tests for identity stability across a 5-step pure translation.
- Unit tests for clean reset on RESET.
- Unit tests for occlusion marking, cumulative_delta, shape_stability decay, and confidence formula.
- Latency: tracker update < 3 ms on typical 64×64 frames.

## Stage 4 — Change-centric Propositions & Verifier Switch

### Rewrite `extract_observed_propositions`

Operate on the list of `TrackedObject` instead of raw ARGA components.  
All propositions that previously used ephemeral `obj_N` now use `persistent_id`.

### Exact formats for new proposition families

```python
# cumulative_motion
AtomicProposition(
    family="cumulative_motion",
    predicate="moved_total_over_N_frames",
    subject_id=persistent_id,
    secondary_id=None,
    value=(dy_total, dx_total),          # tuple of floats
)

# shape_stability
AtomicProposition(
    family="shape_stability",
    predicate="shape_stable" if score > 0.7 else "shape_changed",
    subject_id=persistent_id,
    secondary_id=None,
    value=shape_stability_score,         # float
)

# occlusion (extends object_identity)
AtomicProposition(
    family="object_identity",
    predicate="occluded",
    subject_id=persistent_id,
    secondary_id=occluded_by,            # str | None
    value=True,
)
```

### Definition of “participating TrackedObject”

A `TrackedObject` is **participating** (and therefore subject to the low-confidence UNDECIDED rule) if and only if:

- its `persistent_id` appears in any expected proposition, **or**
- its `persistent_id` appears in any observed proposition that carries a non-zero delta (metric_sign, attribute_delta, relation_delta, cumulative_motion, etc.).

### Additional UNDECIDED condition (now available)

Any participating `TrackedObject` has `confidence < track_confidence_threshold` → `Verdict.UNDECIDED`.


`build_planning_set` receives tracker state and attaches persistent IDs.  
Identity invariant between visual and symbolic channels must be preserved.

### Integration points
- After every real environment step (including RESET) call `tracker.update` / `tracker.reset`.
- `LayeredVerifier` switches to the tracker-based observation path.  
  Keep the pure-ARGA path behind a config flag for ablation.
- Virtual sandbox continues to use pure geometric simulation (tracker is runtime-only).

### Sandbox vs. real verifier disagreement

- Pre-validation inside the virtual sandbox still uses pure geometry and may produce a preliminary verdict.
- The real verifier (with tracker) produces the final verdict.
- If sandbox said FOLLOW but the real verifier says UNDECIDED or NULL → this is expected and normal (tracker sees more).
- If sandbox said NULL but the real verifier says FOLLOW → log a `"sandbox_disagreement"` event for diagnostics. Do not override the real verdict.

## Stage 5 — Telemetry, Audit & Final Hardening

### Audit log
Every `BrusentsovJudgment` (including UNDECIDED) must record:
- verdict
- expected / observed proposition counts
- ambiguity_score, evidence_hint, matching_candidates
- track_confidence_min
- persistent_ids involved
- frame_index, level_id, trajectory_id

### New telemetry counters (`GameSession.harness_telemetry`)

```python
{
    "undecided_count": int,
    "undecided_resolved_by_probe": int,
    "undecided_fallback_to_null": int,
    "false_null_suspects": int,
    "tracker_spawn_count": int,
    "tracker_kill_count": int,
    "ambiguous_match_count": int,
    "occlusion_events": int,
    "cumulative_motion_events": int,
    "low_confidence_tracks": int,
}
```

**Definition of `false_null_suspects` (measurable):**  
Fraction of NULL judgments after which a subsequent probe (if any) recovered the same object at the same location.  
“Same location” means Manhattan distance between the centroid recorded at the moment of the NULL and the centroid after the probe is ≤ 1 pixel.

### Final acceptance criteria (whole contract)

1. All original 191 V10 unit tests pass unchanged.
2. New tests cover:
   - UNDECIDED on ambiguous matching
   - UNDECIDED on low track confidence
   - zero-delta non-confirmed action → UNDECIDED
   - streak limit → NULL (not OMIT)
   - tracker identity stability over 5-step translation
   - clean tracker reset on environmental RESET
   - correct cumulative_delta, occluded flags, confidence formula, shape-stability decay
3. No NULL is ever emitted solely from mismatch with an LLM-generated EXPECT (ISO-10).
4. Evidence probes never exhaust the level action budget under normal conditions.
5. UNDECIDED rate is non-zero but bounded.
6. When `enable_undecided_verdict=False` the system behaves as a pure three-valued judge (UNDECIDED conditions → OMIT).
